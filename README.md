# Просмотры уроков ЦОК

Дашборд просмотров уроков: всего, прирост за день, неделя по дням, топ-5 регионов, просмотры учителей отдельно.

- `index.html` — сайт (GitHub Pages). Данные берёт при открытии у скрипта Google Apps Script.
- `apps-script/Code.gs` — скрипт, который читает выгрузки Metabase из папки на Google Диске и отдаёт сводные цифры.

Обновление данных: положить новую выгрузку (xlsx) в папку на Google Диске.
